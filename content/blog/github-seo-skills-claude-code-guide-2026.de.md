<h2>🛠️ Schritt-für-Schritt-Anleitung: SEO Skills in Claude Code installieren</h2>
<p>Die Integration in Ihre lokale Entwicklungsumgebung ist denkbar einfach:</p>

<h3>Schritt 1: Skill-Verzeichnis erstellen</h3>
<pre><code># Für Claude Code oder Antigravity-Arbeitsbereich:
mkdir -p ~/.claude/skills/maral-seo
# Oder im Projekt-Stammverzeichnis:
mkdir -p .agents/skills/maral-seo</code></pre>

<h3>Schritt 2: Die SKILL.md Regeldatei hinterlegen</h3>
<p>In der <code>SKILL.md</code> definieren Sie die Qualitätskriterien: Server-Side-Rendering (SSR) Metadaten, 45-65 Zeichen Titellänge, LocalBusiness JSON-LD Schema und die Princeton-GEO-Vorgaben.</p>

<h3>Schritt 3: Live-Audit per Terminal-Befehl ausführen</h3>
<pre><code># Vollständiges SEO & GEO Audit Ihrer Live-Website starten:
python .agents/skills/maral-seo/scripts/maral_audit.py https://salihmaral.de</code></pre>

<h2>🤖 Princeton GEO-Standard: Maximale Sichtbarkeit in KI-Suchmaschinen</h2>
<p>Laut der wissenschaftlichen Princeton KDD-Forschung müssen Websites folgende Kriterien erfüllen, um von ChatGPT Search, Perplexity und Claude als primäre Quelle zitiert zu werden:</p>

<blockquote>
<p><strong>Princeton GEO-Regel:</strong> Beantworten Sie die Suchabsicht präzise in den ersten 150 Wörtern, belegen Sie Ihre Expertise (E-E-A-T) mit nachprüfbaren Fakten (z.B. offizieller Google Partner, 17+ Jahre Erfahrung) und nutzen Sie strukturierte Datentabellen (<code>&lt;table&gt;</code>) und Zitatblöcke (<code>&lt;blockquote&gt;</code>).</p>
</blockquote>

<h2>❓ Häufig gestellte Fragen (FAQ)</h2>

<h3>1. Benötige ich kostenpflichtige API-Schlüssel für GitHub SEO Skills?</h3>
<p>Nein. Die meisten Open-Source-Skills prüfen Ihren Quellcode und das Live-DOM vollkommen lokal und kostenfrei ohne externe APIs. Optionale Anbindungen an Ahrefs oder Semrush sind jedoch möglich.</p>

<h3>2. Welche technischen Fehler kann Claude Code automatisch beheben?</h3>
<p>Fehlende Titles/Descriptions, doppelte H1-Tags, fehlerhafte Canonical-URLs, fehlende Schema.org Auszeichnungen, Hreflang-Fehler sowie fehlende Bild-Alt-Attribute werden direkt im Quellcode korrigiert.</p>
